# Exemples de Documents Générés par ClientDocManager

Ce dossier contient des exemples de documents qui peuvent être générés par l'application ClientDocManager. Ces exemples sont destinés à illustrer la qualité, le professionnalisme et la personnalisation des documents produits.

## Types de Documents :
*   **PDF (`pdf/` sous-dossier) :**
    *   Factures Proforma
    *   Spécifications Techniques
    *   Contrats de Vente
    *   Listes de Colisage
    *   Pages de Garde
    *   Etc. (selon les modèles HTML configurés)
*   **Excel (`excel/` sous-dossier) :**
    *   Exportations de données
    *   Modèles Excel remplis (si l'application supporte la génération directe de fichiers Excel remplis ou l'utilisation de modèles Excel comme base).

## Utilisation :
Ces exemples peuvent être utilisés pour :
- Les démonstrations de l'application.
- Les supports marketing (brochures, pages web) pour montrer concrètement les résultats.
- Convaincre les prospects de la capacité de l'application à produire des documents conformes à leurs besoins.

## Génération des Exemples :
Pour créer ces exemples :
1.  Utilisez l'application ClientDocManager avec une base de données de démonstration bien remplie.
2.  Accédez aux fonctionnalités de génération de documents pour un client et un projet fictifs.
3.  Sélectionnez les modèles appropriés (par exemple, `proforma_invoice_template.html` pour une facture proforma PDF).
4.  Remplissez les informations dynamiques nécessaires (détails du client, produits, prix, etc.).
5.  Générez le document.
6.  Sauvegardez le fichier résultant (PDF ou Excel) dans le sous-dossier approprié (`pdf/` ou `excel/`) avec un nom descriptif (par exemple, `exemple_facture_proforma_societe_alpha.pdf`).

Assurez-vous que les données utilisées dans ces exemples sont fictives et professionnelles.

*Les fichiers d'exemples réels doivent être générés via l'application et placés dans les sous-dossiers `pdf/` et `excel/`.*
